# Projets Réalisés

* Réalisation de tests d’intrusion et prestation d’audit sur des copies des systèmes fournies par les clients.
* Déploiement d’outils d’analyse de code et de scanners de vulnérabilités en intégration continue.
* Rédaction de rapports détaillant les vulnérabilités et les correctifs.

*Projet commandité par l'Ingénieur Réseau de l'Université de Rouen Normandie* 
* **Rôle :** Chef d'équipe, coordination de 7 développeurs via Git et Code Review.
* **Réalisation :** Livraison de 5 fonctionnalités majeures en 170 heures. Implémentation de contre-mesures face aux injections XSS et SSTI.
* **Python (Flask), Docker, Nginx, OpenSSL, JS, Nmap, SonarCube**
